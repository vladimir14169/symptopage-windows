# SymptoPage для iPhone — как собрать и запустить

> **Статус на 2026-10-03.** Приложение **собирается** на macOS-машине GitHub Actions (Xcode 26.6, workflow `.github/workflows/ios.yml`). Тесты ядра там проходят: 13/13. Получены неподписанные `SymptoPage-unsigned.ipa` (для iPhone) и `SymptoPage-Simulator.zip`. **На телефоне и в Simulator приложение ещё не запускалось.**
>
> **Быстрый путь без Mac (Windows):** неподписанный `.ipa` нужно подписать своим Apple Account при установке, например через Sideloadly или AltStore. Бесплатный аккаунт даёт профиль на 7 дней (§9, §13). На iPhone включите Режим разработчика (§8). Отличия от Windows описаны в [docs/APPLE_ROADMAP.md](docs/APPLE_ROADMAP.md).

Требования Apple сверены с developer.apple.com на 2026-10-03. Актуальная стабильная Xcode — **27**, ей нужна macOS Tahoe 26.6 или новее. С 28 апреля 2026 App Store Connect принимает только сборки из Xcode 26+ с iOS 26 SDK. Минимальная поддерживаемая версия iOS для SymptoPage — **17**.

---

## 1. Что можно подготовить на Windows

- Скачать исходники (§3) и прочитать их в любом редакторе.
- Запустить Windows-тесты (`pnpm test`): они проверяют общие правила и формат данных, на которых построено iOS-ядро.
- Обновить тексты EN/PL в `core/i18n.js` и выгрузить их для iOS: `pnpm export:i18n`.
- Создать бесплатный Apple Account (appleid.apple.com), если его нет.
- Запустить облачную проверку на Mac-машине GitHub: workflow `.github/workflows/ios.yml` (§11). Для этого нужен репозиторий, куда у вас есть право записи.

**Собрать, подписать и установить приложение на iPhone с Windows нельзя.** Xcode работает только на macOS.

## 2. Для чего нужны Mac и Xcode

Сборка приложения, запуск в Simulator, подпись, установка на iPhone, TestFlight и App Store — всё это требует Mac (Apple Silicon или Intel с поддержкой macOS Tahoe 26.6+) и Xcode 27 (бесплатно в Mac App Store).

## 3. Как получить исходники

На Mac откройте «Терминал» и выполните:

```bash
xcode-select --install          # инструменты командной строки (git), если ещё нет
git clone https://github.com/maxksoongenshin/symptopage-windows.git
cd symptopage-windows
git checkout feature/multi-observation-0.5   # если ветка опубликована; иначе возьмите архив у владельца
```

## 4. Как создать проект (воспроизводимо)

Файл проекта Xcode не хранится в git, его генерирует XcodeGen из `ios/project.yml`:

```bash
# 1) Homebrew, если нет: https://brew.sh
brew install xcodegen
cd ios
xcodegen generate        # создаст ios/SymptoPage.xcodeproj
open SymptoPage.xcodeproj
```

Если XcodeGen поставить нельзя, проект можно создать вручную: Xcode → File → New → Project → iOS App (SwiftUI, Swift), имя `SymptoPage`, iOS 17. Затем перетащите в проект папку `ios/SymptoPage` (с `Assets.xcassets` и `Resources/i18n.json`), удалите созданные шаблоном `ContentView.swift` и второй `@main`, и подключите локальный пакет через File → Add Package Dependencies → Add Local… → `ios/SymptoPageCore`.

Перед сборкой проверьте ядро:

```bash
cd ios/SymptoPageCore
swift test               # тесты на тех же данных, что и Windows-версия
```

## 5. Проверенные версии инструментов

| Инструмент | Версия | Статус |

| Xcode | 27 (Swift 6.4, iOS 27 SDK) | актуальная по developer.apple.com, **не проверялась** на этом проекте |
| macOS | Tahoe 26.6+ | требование Xcode 27 |

| XcodeGen | любая текущая из Homebrew | не проверялась |

После первой успешной сборки впишите сюда реальные версии.

## 6. Team и Bundle Identifier

1. Xcode → Settings → Accounts → «+» → Apple Account: войдите. Бесплатный аккаунт появится как **«Ваше имя (Personal Team)»**.
2. В проекте: target **SymptoPage** → вкладка **Signing & Capabilities** → включите *Automatically manage signing* и выберите **Team**.
3. **Bundle Identifier** должен быть уникальным во всём Apple: замените `app.symptopage.ios` на свой, например `com.yourname.symptopage`. Если Xcode пишет «is not available», измените его ещё раз. Чтобы не править при каждой генерации, впишите его в `ios/project.yml` (`PRODUCT_BUNDLE_IDENTIFIER`) и `DEVELOPMENT_TEAM`.

## 7. Запуск в Simulator

1. Вверху окна Xcode выберите схему **SymptoPage** и устройство, например *iPhone 17*.
2. Нажмите ▶︎ (⌘R). При первой сборке скачиваются пакеты, это займёт несколько минут.
3. Проверьте: пустой первый запуск → добавить врача → Now/Teraz → Журнал → Лекарства → Ещё → Отчёт → Сохранить PDF.

Simulator не заменяет проверку на телефоне: уведомления, Face ID, защита файлов и производительность там ведут себя иначе.

## 8. Подключение iPhone

1. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».
2. Xcode → Window → Devices and Simulators: телефон должен появиться в списке. При первом подключении Xcode готовит устройство, это может занять несколько минут.
3. Включите **Режим разработчика** (iOS 16+): на iPhone Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл. → перезагрузка → «Включить». Этот пункт появляется после первого подключения к Xcode.
4. Позже можно работать по Wi-Fi: в «Devices and Simulators» включите *Connect via network* (телефон и Mac в одной сети).

## 9. Сборка и запуск на телефоне

1. Выберите свой iPhone в списке устройств и нажмите ▶︎.
2. С бесплатным аккаунтом при первом запуске iPhone покажет «Ненадёжный разработчик». Откройте Настройки → Основные → VPN и управление устройством → ваш Apple Account → «Доверять».
3. Ограничения Personal Team (по данным Apple): профиль действует **7 дней** (потом приложение не откроется — пересоберите и установите заново), не больше **3 устройств** и **3 приложений на устройство**, не больше 10 App ID за 7 дней.

## 10. Уведомления: включить и проверить

1. Откройте SymptoPage → Ещё → Настройки → «Показывать напоминания о лекарствах». При первом включении iOS спросит разрешение — нажмите «Разрешить».
2. Если разрешение было отклонено: Настройки iPhone → Уведомления → SymptoPage → Допуск уведомлений.
3. Проверка: в «Лекарства» создайте тестовый курс TEST с временем через 2–3 минуты на сегодня → заблокируйте телефон → дождитесь уведомления. По умолчанию текст без названия лекарства.
4. Проверьте также: отметка «Принято» до наступления времени отменяет уведомление; удаление курса убирает будущие уведомления; режим «Фокусирование» может их скрыть.
5. Ограничения: iOS доставляет уведомления и при закрытом приложении, но **не при выключенном телефоне**. Одновременно планируется до 60 напоминаний, и при каждом открытии приложения список обновляется.

## 11. Диагностика при ошибке

- **Ошибка сборки:** Xcode → Report navigator (⌘9) → последняя сборка → раскройте красные строки. Скопируйте текст ошибки целиком.
- **Сбой при запуске:** Xcode → Debug area (⇧⌘Y), консоль. Отчёты о сбоях на телефоне: Настройки → Конфиденциальность и безопасность → Аналитика и улучшения → Данные аналитики → `SymptoPage-…`.
- **Проблемы подписи:** Signing & Capabilities → кнопка «Try Again» / «Fix Issue»; проверьте Team и уникальность Bundle ID.
- **Ядро отдельно:** `cd ios/SymptoPageCore && swift test` — покажет, какое правило не совпало с Windows-версией.
- **Без Mac:** запустите workflow «iOS core tests and simulator build» (`.github/workflows/ios.yml`) в своём репозитории GitHub. Он выполнит `swift test` и соберёт приложение для Simulator на macOS-машине GitHub.
- Не прикладывайте к сообщению об ошибке `records.json` или резервные копии — в них медицинские данные.

## 12. Локальный запуск, TestFlight и App Store

| | Локально (Xcode) | TestFlight | App Store |
|---|---|---|---|
| Нужен аккаунт | бесплатный Apple Account | Apple Developer Program (~99 USD/год) | Apple Developer Program |
| Кто может установить | ваши устройства, подключённые к Xcode | до 100 внутренних и до 10 000 внешних тестировщиков по приглашению; внешние сборки проходят Beta App Review | все пользователи в выбранных странах |
| Срок | 7 дней (бесплатно) / дольше с платным аккаунтом | сборка действует 90 дней | бессрочно |
| Что ещё нужно | — | архив (Product → Archive), загрузка в App Store Connect | иконка (логотип), политика конфиденциальности, App Privacy, описание с медицинским дисклеймером, решение по лицензии, App Review |

## 13. Ограничения выбранного способа подписи

- **Automatic signing + Personal Team** — бесплатно и просто, но: 7-дневные профили, лимиты устройств и приложений, нет TestFlight и App Store, нет части capabilities (например, push-уведомлений с сервера; локальным уведомлениям SymptoPage это не мешает).
- **Automatic signing + платная команда** снимает 7-дневный лимит и даёт TestFlight и App Store. Сертификаты и профили Xcode создаёт сам.
- Ручная подпись (manual) нужна только для CI/автоматизации выпуска. Её настройка не входит в эту версию.
