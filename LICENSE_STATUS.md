# Licence status — decision needed from the owner

**Current state (2026-10-03): the repository has no licence.** GitHub reports `license: null`. A public repository without a licence is **not** open source: by default, all rights are reserved by the copyright holder(s), and others may view the code on GitHub but have no permission to copy, modify or redistribute it.

This change set **does not add or change any licence**. No MIT/Apache/GPL file was added.

## What the owner needs to decide

1. **Copyright holder(s)** — the exact name(s) for the notice (person or organisation), e.g. `© 2026 <name>`. Contributors so far: the repository owner (`maxksoongenshin`), the colleague who made the interface mock-ups, and this change set.
2. **Licence model** — one of:
   - keep "all rights reserved" (proprietary; fine for a private product);
   - a permissive open-source licence (MIT, Apache-2.0);
   - a copyleft licence (GPL-3.0, MPL-2.0);
   - source-available/custom terms.
3. **Frontend mock-ups** — written confirmation from the colleague that the design may be used in SymptoPage under the chosen terms (or a transfer/licence of rights).
4. **Logo** — owner of the logo and permitted use (app icon, installer, App Store).
5. **App Store** — if iOS distribution is planned, note that some copyleft terms (e.g. GPL) are commonly considered incompatible with App Store terms; check before choosing.
