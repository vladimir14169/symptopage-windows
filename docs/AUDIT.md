## Ограничения среды выполнения работы

- Нет прав `push` в `maxksoongenshin/symptopage-windows` (только `pull`). Работа ведётся в локальной ветке `feature/multi-observation-0.5`.
- Хост — Windows 10 Pro 19045 с WSL1. Electron-тесты и сборки выполнены на самой Windows через portable Node 24.9.0.
- Swift-тулчейн (6.4) под WSL1 зависает даже на `print("hello")`; Mac отсутствует. iOS-код не компилировался.
