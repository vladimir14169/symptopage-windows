# SymptoPage для Windows — установка, запуск и сборка

## 1. Что скачать

Нужна Windows 10 или 11, 64-битная. Есть три варианта одного и того же приложения версии 0.5.0:

| Файл | Когда выбирать |
|---|---|
| `SymptoPage-0.5.0-Windows-Setup.exe` | Обычная установка: ярлык в меню «Пуск», удаление через «Параметры → Приложения». **Нужна для уведомлений Windows** (см. §4). |
| `SymptoPage-0.5.0-Windows-Portable.exe` | Запуск без установки. |
| `SymptoPage-0.5.0-Windows-x64.zip` | Распакуйте **всю** папку и запустите `SymptoPage.exe`. Не переносите EXE отдельно от соседних файлов. |

Проверить целостность файла можно так. Откройте PowerShell в папке с файлом и выполните:

```powershell
Get-FileHash .\SymptoPage-0.5.0-Windows-Setup.exe -Algorithm SHA256
```

Сравните результат с `SHA256SUMS.txt`, лежащим рядом со сборкой.

### Цифровая подпись

**Сборки 0.5.0 не подписаны** (`signExecutable: false`), и сертификата издателя нет. Поэтому Windows SmartScreen может показать «Windows защитила ваш компьютер». Если файл получен из доверенного источника и контрольная сумма совпала, нажмите «Подробнее» → «Выполнить в любом случае». Подписанной эту сборку считать нельзя.

## 2. Установка

1. Запустите `Setup.exe` и выберите папку (по умолчанию установка идёт только для текущего пользователя).
2. Запустите SymptoPage из меню «Пуск».
3. Выберите язык (English / Polski) в правом верхнем углу. Выбор сохраняется.
4. При первом запуске данных нет. Укажите специальность врача, дату визита и причину — это начало наблюдения.

## 3. Обновление с 0.4.0

Просто установите 0.5.0 поверх. При первом запуске данные 0.4.0:
- копируются без изменений в `%APPDATA%\SymptoPage-Windows\backups\<время>-pre-migration-v1.json`;
- переводятся в новый формат: визит становится наблюдением у врача, записи и ежедневные ответы сохраняются;
- приложение коротко сообщает, сколько записей перенесено.

Удаление программы данные **не удаляет**.

Проверено на этом компьютере 2026-10-03: установили 0.4.0 из релиза, создали визит и запись, поставили 0.5.0 поверх. Данные перенесены, копия создана.

## 4. Напоминания о лекарствах — как они работают на Windows

- Напоминание показывается, только пока SymptoPage запущен. Чтобы получать напоминания при закрытом окне, включите «Настройки → Работать в области уведомлений после закрытия окна». Значок появится в трее, а выйти можно через его меню.
- При выключенном компьютере, в спящем режиме или в гибернации напоминаний **нет**. После пробуждения старые напоминания (старше 30 минут) не показываются. Приём остаётся «ещё не отмечен», и его можно отметить в разделе «Лекарства».
- Windows может скрыть уведомления: «Параметры → Система → Уведомления» (для SymptoPage), «Не беспокоить» или «Помощник фокусировки». Кнопка «Отправить тестовое уведомление» в настройках помогает это проверить.
- Portable- и ZIP-версии могут не показывать системные уведомления: по документации Electron, Windows связывает уведомления с ярлыком в меню «Пуск», который создаёт установщик. На этом компьютере это не проверялось. Для напоминаний используйте `Setup.exe`.
- По умолчанию в тексте уведомления нет названия лекарства, ведь оно видно на экране блокировки. Название можно включить в настройках.
- Уведомление — не отметка о приёме. Нажмите «Принято», «Пропущено» или «Напомнить позже».

## 5. Где данные и как их сохранить

- Данные: `%APPDATA%\SymptoPage-Windows\records.json`, вложения — в `attachments\`, автоматические копии — в `backups\`. Папку открывает кнопка «Настройки → Показать папку данных».
- Данные **не зашифрованы**. Если компьютером пользуются другие люди, защитите учётную запись Windows паролем и включите BitLocker.
- Резервное копирование и перенос описаны в [docs/BACKUP_RU.md](docs/BACKUP_RU.md).

## 6. Для разработчика: сборка из исходников

Нужны Node.js 24 (или ≥ 22.12) и pnpm 11.19.0 (`npx pnpm@11.19.0 …`).

```powershell
pnpm install --frozen-lockfile
pnpm start          # запуск
pnpm test           # 38 тестов ядра, хранения, напоминаний, часовых поясов, переводов
pnpm test:ui        # 5 сквозных Electron-тестов (Playwright)
$env:CSC_IDENTITY_AUTO_DISCOVERY="false"; pnpm build:win   # dist\: Setup.exe, Portable.exe, x64.zip
```

Контрольные суммы считаются так:

```powershell
Get-FileHash dist\*.exe,dist\*.zip -Algorithm SHA256
```

Проверка установленной сборки на отдельной папке данных (настоящий профиль не затрагивается):

```powershell
node scripts\verify-install.cjs "<путь>\SymptoPage.exe" C:\temp\sp-test expect-empty
```

CI: `.github/workflows/windows.yml` повторяет те же шаги на `windows-latest`.

## 7. Если что-то не так

| Симптом | Что делать |
|---|---|
| «Не удалось открыть данные» | Файл не перезаписан. Восстановите автоматическую копию из списка или выберите «Сохранить повреждённый файл и начать заново» (файл переименуется в `records.unreadable-….json`). |
| Нет уведомлений | Пройдите §4 и отправьте тестовое уведомление. |
| SmartScreen блокирует запуск | См. «Цифровая подпись» в §1. |
| Нужна диагностика | Сообщите версию (Настройки → О SymptoPage) и код ошибки с экрана. Не присылайте `records.json` — в нём медицинские данные. |
